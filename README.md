# AutoRent — сайт аренды автомобилей

## 1. Описание проекта

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

**Тема:** «Сайт по аренде автомобилей».

Сайт предназначен для поиска и аренды автомобилей на определённый срок. Пользователь может:

1. просмотреть доступные автомобили и познакомиться с их характеристиками;
2. выбрать подходящий вариант по марке, классу и стоимости;
3. рассчитать цену аренды (с учётом срока, скидок и дополнительных услуг);
4. оформить заявку на бронирование.

Backend пока не подключён: заявка проверяется и «отправляется» в браузере (имитация), данные автомобилей хранятся в файле `js/cars.js`.

## 5. Описание страниц

### Главная страница (`index.html`)
- **Первый экран (hero)** — заголовок, форма быстрого подбора (класс, марка, цена за сутки) и блок с большим фото автомобиля. Миниатюры под фото переключают показанный автомобиль.
- **Форма быстрого подбора** отправляет выбранные значения на страницу каталога, где фильтры включаются автоматически.
- **Цифры** — краткая информация о сервисе.
- **Классы автомобилей** — 4 карточки со ссылками на страницы классов.
- **«Как взять автомобиль в аренду»** — 4 шага.
- **Скидки и дополнительные услуги** — две таблицы с ценами.
- Блок условий аренды.

### Каталог (`catalog.html`)
Показывает все 20 автомобилей. Слева — фильтры, справа — список:
- поиск по названию (например, «Camry»);
- выбор марки;
- класс (можно выбрать несколько);
- статус: только свободные, хиты, новинки, со скидкой, избранное;
- цена за сутки «от» и «до».

Фильтры работают сразу при изменении. Над списком — счётчик «Найдено: N автомобилей» и сортировка (по умолчанию, сначала дешёвые, сначала дорогие, по названию). Если ничего не найдено, показывается сообщение; кнопка «Сбросить» возвращает все автомобили.

### Классы (`category.html`)
Адрес вида `category.html?category=suv`. Страница показывает описание класса, требования к водителю (возраст и стаж) и автомобили этого класса списком. Внизу — переходы к другим классам и ко всему каталогу. Допустимые значения: `economy`, `business`, `suv`, `sport`. Если параметр не указан или неверный, открывается класс `suv`.

### Карточка автомобиля (`product.html`)
Адрес вида `product.html?id=9`. Если номер неверный или не указан, показывается автомобиль №1. На странице:
- большое фото (увеличивается при наведении), рейтинг, цена, наличие, краткие особенности;
- кнопки «Забронировать», «Рассчитать стоимость», «В избранное»;
- якорная навигация по разделам страницы;
- описание и подробная таблица характеристик (разделена на группы);
- **калькулятор стоимости аренды** (см. раздел 7);
- таблица сравнения с тремя ближайшими по цене автомобилями того же класса;
- условия аренды (возраст, залог, пробег, оплата, отмена);
- похожие автомобили.

Если автомобиль занят (Bugatti Chiron), кнопки бронирования отключены.

### Контакты (`contacts.html`)
Телефон, e-mail, адрес, режим работы, кнопка открытия формы заявки, раздел «Где получить автомобиль» (офис, аэропорт, доставка) и раздел «Частые вопросы» — 10 подробных вопросов и ответов в раскрывающихся блоках `details`.

## 6. Данные автомобилей (`js/cars.js`)

Файл содержит четыре набора данных:

- `CLASSES` — классы автомобилей: название, описание, минимальный возраст и стаж, картинка;
- `EXTRAS` — дополнительные услуги и их цена за сутки (детское кресло, GPS, полная страховка, водитель);
- `DISCOUNTS` — скидки за срок аренды;
- `CARS` — список из 20 автомобилей.

Поля автомобиля: `id`, `brand`, `model`, `img`, `cls` (класс), `body` (кузов), `color`, `year`, `gearbox`, `engine`, `fuel`, `power`, `drive`, `seats`, `trunk`, `consumption`, `price` (цена за сутки), `old` (старая цена, если есть скидка), `deposit` (залог), `tag` (`hit`, `new`, `discount` или пусто), `out` (автомобиль занят), `rating`, `reviews`, `desc`.

**Чтобы добавить автомобиль:** положите картинку в `images/`, добавьте объект в массив `CARS` с новым `id` — он автоматически появится в каталоге, в форме заявки, на странице класса и получит свою карточку `product.html?id=...`. Цены в рублях за сутки.

## 7. Как считается стоимость аренды

1. **Количество суток** = разница между датой окончания и датой начала. Минимум — 1 сутки (в том же дне — тоже 1 сутки). Если дата окончания раньше даты начала, расчёт не выполняется и показывается ошибка.
2. **База** = цена за сутки × количество суток.
3. **Скидка за срок** (применяется только к стоимости автомобиля):
   - от 3 суток — 5%;
   - от 7 суток — 10%;
   - от 14 суток — 15%.
4. **Дополнительные услуги** = цена услуги за сутки × количество суток:
   - детское кресло — 300 ₽;
   - GPS-навигатор — 250 ₽;
   - полная страховка — 700 ₽;
   - водитель — 2 500 ₽.
5. **Итого** = база − скидка + услуги. Залог в итог не входит, он возвращается при сдаче автомобиля.

*Пример:* Nissan X-Trail (3 500 ₽/сутки), 3 суток: 3 500 × 3 = 10 500 ₽, скидка 5% = −525 ₽, итого 9 975 ₽. Если добавить GPS: +750 ₽, итого 10 725 ₽.

## 8. Модальное окно бронирования

Открывается кнопками «Арендовать», «Забронировать» и другими. Поля формы:

| Поле | Обязательное | Проверка |
| --- | --- | --- |
| Автомобиль | да | выбор из списка (занятые недоступны) |
| Имя | да | не менее 2 символов |
| E-mail | да | формат `example@mail.ru` |
| Телефон | да | формат `+7 (900) 000-00-00`, подставляется автоматически при вводе |
| Начало аренды | да | не раньше сегодняшнего дня |
| Окончание аренды | да | не раньше даты начала |
| Место получения | да | офис, аэропорт или доставка |
| Дополнительные услуги | нет | флажки |
| Комментарий | нет | — |
| Способ связи | нет | по телефону или по e-mail |
| Согласие на обработку данных | да | флажок |

Как работает окно:
- итоговая стоимость пересчитывается при каждом изменении формы;
- если окно открыто со страницы автомобиля, автомобиль, даты и услуги берутся из калькулятора;
- при ошибках в начале формы появляется список ошибок со ссылками на поля, у каждого поля — своё сообщение (`aria-invalid`, `aria-describedby`);
- закрывается крестиком, кнопкой «Закрыть», клавишей Esc и кликом по затемнённому фону; при открытии страница не прокручивается, после закрытия фокус возвращается на кнопку;
- после успешной отправки (имитация, 0,7 с с индикатором загрузки) показывается сообщение с автомобилем, датами и суммой.

## 9. Интерактивные элементы и эффекты

- карточки автомобилей: подъём и тень при наведении, увеличение фото, подсветка рамки при фокусе;
- кнопки: изменение цвета, лёгкий подъём при наведении, нажатие, состояния `:focus-visible` и `:disabled`;
- пункты меню: подсветка при наведении, активная страница выделена и имеет `aria-current="page"`;
- карточки классов, преимуществ, шагов, контактов и цифр — подъём при наведении;
- строки таблиц подсвечиваются при наведении;
- вопросы FAQ раскрываются по клику;
- кнопка «В избранное» (`aria-pressed`): состояние сохраняется в `localStorage`, избранное можно отфильтровать в каталоге;
- шапка сайта закреплена при прокрутке;
- в шапке между меню и кнопкой «Забронировать» размещён номер телефона;
- в подвале каждой страницы слева контакты, в центре ссылки «Каталог», «Классы», «Контакты» (оранжевые кнопки), справа кнопка «Забронировать»; слева — телефон, e-mail, адрес и режим работы, справа — кнопка «Забронировать»;
- кнопки в карточках: «Арендовать» и «Подробнее» одинакового размера, рядом кнопка-сердечко «В избранное».

## 10. CSS и БЭМ

- в `:root` заданы переменные: цвета, отступы, скругления, тени, ширина контейнера;
- классы названы по методологии БЭМ, например `product-card`, `product-card__title`, `product-card--featured`;
- основные блоки: `site-header`, `site-nav`, `hero`, `hero-search`, `products-grid`, `product-card`, `badge`, `stock`, `catalog-layout`, `catalog-filters`, `filters-form`, `category-card`, `product-details`, `rental-calc`, `data-table`, `order-dialog`, `order-form`, `order-summary`, `faq`, `site-footer`;
- модификаторы карточек: `--featured` (хит), `--new`, `--discount`, `--unavailable`, `--horizontal`, `--favorite`;
- **Flexbox** используется для меню, шапки и кнопок, **Grid** — для сеток карточек, каталога с фильтрами, формы и калькулятора;
- адаптивность задана через `@media` для ширины 1000, 800 и 600 px;
- учитывается `prefers-reduced-motion` (анимации отключаются).

## 11. Доступность

- ссылка «Перейти к основному содержимому» (skip-link);
- хлебные крошки с `aria-label`, `aria-current`;
- у полей формы есть подписи `label`, подсказки и сообщения об ошибках связаны через `aria-describedby`;
- счётчик результатов и итоговая сумма озвучиваются через `role="status"`;
- таблицы имеют `caption`, `scope`, прокрутку внутри `table-scroll`;
- видимый фокус на всех интерактивных элементах.

## 13. Почему без фреймворков

В проекте сознательно не используются Bootstrap и другие фреймворки: вся вёрстка, компоненты и логика написаны вручную. Так видно, как устроены основы:

| Элемент | Как сделан |
| --- | --- |
| Сетки карточек, таблиц и контактов | CSS Grid и Flexbox |
| Раскрывающиеся вопросы (FAQ) | элементы `details` и `summary` со своим оформлением |
| Модальное окно | нативный элемент `dialog` и собственный JavaScript |
| Уведомление об отправке заявки | собственный компонент `toast` (показ 10 секунд, закрытие крестиком) |
| Сворачиваемые фильтры на телефоне | кнопка с `aria-expanded` и класс `is-open` |
| Адаптивность | собственные `@media`-правила |

В дальнейшем сайт можно перенести на фреймворк (например, React или Vue) и добавить серверную часть.
